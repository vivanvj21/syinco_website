## 2. Key Architectural Component Highlights

### 2.1 ProductCard (`src/components/business/ProductCard.tsx`)
- Primary atomic technical presentation card.
- Consumed by:
  - `app/page.tsx`
  - `components/business/CatalogueDiscoveryEngine.tsx`
- **Critical Invariant:** Enforces 4:3 aspect ratio, compare toggle, classification badge, OEM tag, 3 scannable metrics, and fallback to `ProductPlaceholder` when asset is rejected or missing.

### 2.2 ProductPlaceholder (`src/components/technical/ProductPlaceholder.tsx`)
- Precision SVG CAD blueprint wireframe fallback.
- Consumed by:
  - `app/products/[categorySlug]/[productSlug]/page.tsx`
  - `components/business/ProductCard.tsx`

### 2.3 ApplicationDiscoveryMatrix (`src/components/business/ApplicationDiscoveryMatrix.tsx`)
- Interactive 3-step decision matrix matching research problems to verified equipment.
- Consumed by:
  - `components/business/CataloguePageClient.tsx`

### 2.4 Navigation Shell (`Header`, `MegaMenu`, `Footer`)
- Top-level application frame rendered globally via `src/app/layout.tsx`.
