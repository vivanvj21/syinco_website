## 1. Executive Forensic Diagnosis: Why Products Are Leaking Onto Homepage

### Root Cause Analysis
The massive product leakage on the homepage is directly caused by a **hardcoded unconstrained array mapping** in `src/app/page.tsx` line 227.

```tsx
// File: d:\Syinco\src\app\page.tsx
// Line 4:
import { allProducts } from "@/data/products";

// Line 203-231 (Section 5 — Flagship Systems Showcase):
<section aria-label="Flagship Hardware Showcase" ...>
  ...
  <div className="space-y-4">
    {allProducts.map((prod) => (
      <ProductCard key={prod.id} product={prod} />
    ))}
  </div>
</section>
```

### Code Trace
1. **Caller View:** `src/app/page.tsx` line 227 executes `.map()` directly over `allProducts`.
2. **Exported Variable:** `allProducts` is imported from `src/data/products/index.ts`.
3. **Source Registry Definition:** In `src/data/products/index.ts` lines 26-35:
   ```ts
   export const allProducts: Product[] = [
     zem3ProductData,                 // 1 Wave-1 Flagship
     ...wave1FlagshipProducts,        // 7 Wave-1 Flagships
     nxdsProductData,                 // 1 Edwards vacuum pump
     ...edwardsProducts,              // 67 complementary Edwards families
     chinoIrcaProductData,            // 1 Chino pyrometer
     ...fujiSpsProducts,              // 5 Fuji SPS systems
     ...wave2CatalogueFamilyProducts, // 40 Wave-2 secondary families
     ...wave3HeldBackProducts,        // 3 Wave-3 held-for-clarification items
   ];
   ```
4. **The Critical Defect:**
   - Section 5 of the homepage is labeled: **'Benchmarks: Verified Flagship Equipment'**.
   - The intended design was to display ONLY the **8 Flagship Systems** (`isFlagshipProduct` or `FLAGSHIP_PRODUCT_IDS` or `wave1FlagshipProducts`).
   - Instead, the component mapped `allProducts` without ANY `.filter()` or `.slice()`, causing all **125 systems** (including industrial vacuum valves, secondary gauges, and held-back items) to render down the homepage, generating a massive 1.7 MB HTML document.
